# IDEATE + SELECT
Generate 5 commercially distinct concepts from the market brief.

Score each 0-100:
- market_fit
- hook
- originality
- series_potential

Reject concepts that are overly similar to a named existing work.
For each concept output: working title, one-line hook, protagonist, core desire, conflict engine, novelty, expected audience.
Select the highest viable concept. If human concept approval is enabled, stop only at this explicit gate.
