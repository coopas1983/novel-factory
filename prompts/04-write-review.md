# WRITE + REVIEW
Write exactly one outlined chapter at a time.

Before writing, load only:
- relevant canon
- active character state
- previous chapter summary
- unresolved hooks relevant to this chapter
- chapter outline
- style guide

After writing, independently score:
hook, progression, character, prose, payoff.
List blocking issues and continuity conflicts.
If the quality gate fails, revise the same chapter; do not advance.
